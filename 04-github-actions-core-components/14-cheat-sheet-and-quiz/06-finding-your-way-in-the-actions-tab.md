# 🗺️ Finding your way in the Actions tab

| You want | Path |
|---|---|
| A step's log | Actions → run → job → expand the step |
| Why it failed | Run → red job → red step → last lines |
| Files it produced | Run → Summary → Artifacts |
| To try again | Run → Re-run jobs |
